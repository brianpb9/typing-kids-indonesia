🇮🇩Bahasa Indonesia

Ringkasan: Poppu Typing Kids tidak mengumpulkan atau mengirimkan data pribadi apa pun. Tanpa iklan, tanpa pembelian dalam aplikasi, tanpa pelacak, tanpa SDK pihak ketiga. Semua kemajuan belajar tersimpan hanya di perangkat, dan aplikasi dapat dimainkan sepenuhnya offline.

1. Data yang disimpan di perangkat (hanya lokal)

Agar kemajuan belajar tidak hilang, aplikasi menyimpan data berikut di penyimpanan lokal perangkat (localStorage). Data ini tidak pernah meninggalkan perangkat:

  • Kemajuan belajar: bintang, misi selesai, tingkat kesulitan, tema kata, bahasa (Indonesia/Inggris), tutorial, misi harian/mingguan, dan rentetan hari bermain.
  • Statistik belajar: jumlah tombol ditekan, kesalahan ketik, dan total waktu bermain — ditampilkan sebagai ringkasan untuk orang tua.
  • Lencana/prestasi dan penguasaan kata.
  • Pengaturan aksesibilitas (kontras tinggi, teks besar) dan pengaturan suara.
  • Mode kelas: kode kelas 4 huruf dan papan peringkat (nama panggilan + bintang). Papan peringkat hanya tersimpan di perangkat masing-masing — tanpa sinkronisasi antarperangkat, tanpa server kelas.
  • Nama panggilan anak/pemain jika orang tua/guru mengetiknya sendiri (opsional, tersimpan lokal).

2. Analitik opsional (opt-in, hanya lokal)

  • Nonaktif secara bawaan; hanya berjalan jika orang tua mengaktifkannya (opt-in).
  • Hanya mencatat nama kejadian (mis. mission_start, star_earned, mission_win) beserta waktu — tanpa identitas, lokasi, atau data perangkat.
  • Maksimal 200 kejadian terakhir, tersimpan di perangkat. Tidak ada pengiriman ke server mana pun; tidak ada Google Analytics, Firebase, atau layanan sejenis.

3. Data yang TIDAK kami kumpulkan

  • Nama lengkap, alamat, email, nomor telepon, atau data identitas lain.
  • Lokasi, foto, kamera, mikrofon, kontak, atau file perangkat.
  • ID iklan, sidik perangkat, cookie pelacak, atau data lintas aplikasi.

Aplikasi tidak memiliki akun, login, atau registrasi dalam bentuk apa pun.

4. Koneksi jaringan

  • Setelah dimuat pertama kali, aplikasi bekerja sepenuhnya offline (Progressive Web App).
  • Satu-satunya permintaan jaringan adalah memuat file aplikasi itu sendiri (kata, gambar, suara) dari domain kami sendiri (typing.poppu.world). Hosting kami (Vercel) dapat menyimpan log server standar (alamat IP, waktu akses) sebagai bagian dari operasi hosting; log ini tidak kami gunakan untuk mengidentifikasi atau melacak pengguna. Lihat kebijakan privasi Vercel.
  • Tidak ada panggilan jaringan ke pihak ketiga untuk iklan, analitik, atau pelacakan.

5. Fitur berbagi (share)

Tombol "Bagikan" pada layar orang tua (ringkasan kemajuan, sertifikat) hanya aktif saat tombol ditekan, melalui lembar berbagi bawaan sistem operasi. Isinya hanya teks/gambar yang terlihat di layar, dan pengguna memilih sendiri tujuannya. Tanpa ditekan, tidak ada data yang keluar dari perangkat.

6. Privasi anak (COPPA & GDPR-K)

  • Dirancang untuk anak usia 5–6 tahun; kami tidak mengumpulkan informasi pribadi dari anak dalam bentuk apa pun, sesuai prinsip COPPA dan perlindungan data anak GDPR.
  • Tanpa iklan (termasuk iklan berbasis perilaku), tanpa pembelian, tanpa langganan, tanpa monetisasi apa pun.
  • Karena tidak ada data yang dikumpulkan atau dikirim, tidak ada data anak di server kami.

7. Penghapusan data

Semua data tersimpan di perangkat Anda. Hapus melalui pengaturan browser/perangkat (Clear site data) atau dengan mencopot pemasangan aplikasi. Setelah itu tidak ada salinan data yang tersisa di mana pun.

8. Perubahan kebijakan

Jika kebijakan berubah, tanggal "Berlaku efektif" diperbarui dan versi terbaru selalu tersedia di halaman ini.

🇬🇧English

Summary: Poppu Typing Kids does not collect or transmit any personal data. No ads, no in-app purchases, no trackers, no third-party SDKs. All learning progress is stored on the device only, and the app works fully offline.

1. Data stored on the device (local only)

To keep learning progress, the app stores the following in the device's local storage (localStorage). This data never leaves the device:

  • Learning progress: stars, completed missions, difficulty, word theme, language (Indonesian/English), tutorial, daily/weekly missions, and play streak.
  • Learning statistics: keys pressed, typing mistakes, and total play time — shown as a summary for parents.
  • Achievements/badges and word mastery.
  • Accessibility settings (high contrast, large text) and mute preference.
  • Classroom mode: a 4-letter class code and a leaderboard (nickname + stars). The leaderboard lives only on each device — no cross-device sync, no classroom server.
  • A child/player nickname only if a parent/teacher types it in settings (optional, stored locally).

2. Optional analytics (opt-in, local only)

  • Off by default; runs only if a parent explicitly opts in.
  • Records only event names (e.g. mission_start, star_earned, mission_win) with timestamps — no identity, location, or device data.
  • Capped at the last 200 events, stored on the device. Nothing is sent to any server; no Google Analytics, Firebase, or similar services.

3. Data we do NOT collect

  • Full name, address, email, phone number, or any other identity data.
  • Location, photos, camera, microphone, contacts, or device files.
  • Advertising IDs, device fingerprints, tracking cookies, or cross-app data.

The app has no accounts, login, or registration of any kind.

4. Network access

  • After the first load, the app works fully offline (Progressive Web App).
  • The only network requests load the app's own files (words, images, sounds) from our own domain (typing.poppu.world). Our host (Vercel) may keep standard server logs (IP address, access time) as part of hosting operations; we do not use them to identify or track users. See Vercel's privacy policy.
  • No third-party network calls for ads, analytics, or tracking.

5. Share feature

"Share" buttons on parent-facing screens (progress summary, certificate) activate only when tapped, via the operating system's native share sheet. Only the on-screen text/image is shared, and the user chooses the destination. Without a tap, no data leaves the device.

6. Children's privacy (COPPA & GDPR-K)

  • Designed for children aged 5–6; we do not collect personal information from children in any form, following COPPA and the GDPR's children provisions.
  • No advertising (including behavioral ads), no purchases, no subscriptions, no monetization of any kind.
  • Because no data is collected or transmitted, no children's data exists on our servers.

7. Data deletion

All data resides on your device. Delete it via your browser/device settings (Clear site data) or by uninstalling the app. Afterwards, no copy remains anywhere.

8. Changes to this policy

If this policy changes, the effective date is updated and the latest version is always available on this page.

9. Contact

Privacy questions: hdrvstudio@gmail.com
